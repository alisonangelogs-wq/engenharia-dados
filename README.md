
# Portfólio de Engenharia de Dados

## Sobre

Este repositório reúne projetos práticos desenvolvidos para demonstrar conhecimentos em Engenharia de Dados, programação, bancos de dados, integração e processamento de informações.

Os projetos são desenvolvidos de forma incremental, com foco em aprendizado prático, organização de código, qualidade dos dados e documentação técnica.

## Tecnologias

- Python
- SQL
- PostgreSQL
- Pandas
- SQLAlchemy
- Docker e Docker Compose
- Apache Airflow
- Pytest
- Git e GitHub

## Projetos

| Projeto | Descrição | Status |
|---|---|---|
| 01 - Pipeline ETL | Controle de jornada de funcionários com Python e PostgreSQL | Concluído |
| 02 - Data Warehouse | Modelagem dimensional | Planejado |
| 03 - Apache Airflow | Orquestração de processos | Planejado |
| 04 - Análise de Dados | Indicadores e consultas SQL | Planejado |
| 05 - Cloud | Engenharia de dados em nuvem | Planejado |

## Objetivo

Desenvolver soluções práticas de Engenharia de Dados, aplicando boas práticas de programação, organização, documentação, versionamento e processamento de dados.
